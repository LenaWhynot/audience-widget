# Audience Widget

Виджет аудитории на рабочем столе Mac. Показывает суммарное число подписок, счётчик и изменение за день по каждому выбранному аккаунту LiveDune. Требуется macOS 13 или новее. Сборка Universal2 подходит для Apple Silicon и Intel и запускается без Python, Node или отдельного сервера.

[Скачать приложение для Mac](https://github.com/LenaWhynot/audience-widget/releases/latest/download/AudienceWidget-1.0.0-macOS-Universal.zip) · [Релиз и контрольная сумма SHA-256](https://github.com/LenaWhynot/audience-widget/releases/latest)

Сборка имеет локальную подпись ad-hoc. При первом запуске macOS может запросить подтверждение в «Конфиденциальность и безопасность».

## Перед подключением

Нужен собственный кабинет LiveDune, аккаунты на Dashboard, API-ключ и достаточная квота API на вашем тарифе/пакете. Ключ берётся на [LiveDune → Настройки → API](https://pro.livedune.com/settings/api). Виджет не добавляет социальные аккаунты за вас и не даёт бесплатного доступа к данным. Условия и объёмы API проверяйте в [действующих тарифах LiveDune](https://livedune.com/ru/pricing/); документация авторизации — [официальный OpenAPI](https://api.livedune.com/docs/openapi.json).

При интервале 15 мин один выбранный аккаунт использует до 96count-запросов в день,≈2880 за 30 дней; шесть —≈17280 за 30 дней. Дополнительно идут запросы списка при настройке и проверки квоты. Фактический расход меньше, когда Mac спит или приложение закрыто. Остаток показывается при выборе; исчерпание квоты/ошибка доступа приостанавливают обновления. Другие приложения могут расходовать ту же квоту. Покупки и автоматической оплаты в виджете нет.

## Установка и первый запуск

1. Распакуйте ZIP и перенесите `Audience Widget.app` в папку «Программы».
2. Откройте приложение. Сначала будет пустая карточка «Подключить LiveDune»; чужих данных и ключей в ней нет.
3. Нажмите подключение, откройте свой LiveDune API и вставьте ключ только в поле самого приложения. Ключ не надо отправлять в чат.
4. После проверки выберите до 12 аккаунтов и нажмите «Показать выбранные аккаунты».

### Подпись и macOS

Эта сборка подписана локальной ad-hoc подписью. Developer ID и Apple notarization отсутствуют, поэтому macOS может заблокировать первый запуск скачанного файла. Это не проверенное Apple приложение. Сначала проверьте источник и внешнюю SHA256 архива из файла рядом с ZIP. Внутренний `SHA256.txt` содержит суммы файлов приложения, исходников и инструкции.

Если вы доверяете именно этому файлу, после попытки открыть его используйте штатный путь Apple: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть», затем подтвердите открытие. [Официальная инструкция Apple](https://support.apple.com/102445). Не отключайте Gatekeeper целиком и не игнорируйте предупреждение, что программа повреждена или содержит вредоносный код: в таком случае остановитесь и получите проверенную копию.

## Управление

Шестерёнка в карточке: обновление, подключение/выбор аккаунтов, пауза, уведомления, удаление подключения, скрытие и завершение. После скрытия повторное открытие приложения показывает ту же карточку. После завершения откройте приложение заново. Карточка под обычными окнами, без значка в Dock и строке Mac; её можно перемещать за фон.

В этой первой share-версии автозапуск не регистрируется. После перезагрузки откройте приложение вручную. Сон приостанавливает работу; после пробуждения — тихое обновление. Обновления идут только при работающем приложении и сети.

## Что означают цифры

Сумма подписок не является уникальной аудиторией. Прирост — чистое изменение общего счётчика между наблюдениями, не список новых людей. Первый день считается с первого снимка; при пропуске нескольких суток baseline создаётся заново. Время проверки не означает свежесть провайдера: точное время сбора LiveDune API здесь не сообщает. Возраст последнего успешного снимка доступен через подсказку, при ошибке сохраняются старые данные и появляется значок ошибки. Неизвестные counts — «—».

Недельной дельты, лайков и просмотров в этой версии нет. Сводку отдельных постов нельзя честно выдавать за статистику всего аккаунта. Уведомления — тихие локальные popup по новому положительному изменению выше уже уведомлённого максимума, не чаще одного за 15 мин. Первый запуск, выбор аккаунтов, пробуждение и продолжение после паузы не создают уведомления. Падение/возврат к уже уведомлённому максимуму не дублируется. Системный Focus для custom popup не гарантирован; их можно выключить шестерёнкой.

## Ключ и удаление

Ключ хранится в macOS Keychain, service `app.audiencewidget.desktop.share`, account `livedune-token`, label `Audience Widget · LiveDune`. Он отправляется только HTTPS-запросами к `api.livedune.com`. Авторизация API требует query-параметр; приложение не печатает URL/ключи в логи. Cookies/cache/credential storage URLSession отключены, внешние redirects запрещены. Приложение делает только GET/accounts,GET/info,GET/accounts/{id}/analytics. Обратных отправок, публикаций и телеметрии нет.

«Удалить подключение» удаляет только этот Keychain item и собственный локальный выбор/снимки, отменяет текущий сбор и возвращает пустую настройку. Аккаунты LiveDune не удаляются. При смене ключа отсчёт создаётся заново. После обновления ad-hoc приложения доступ Keychain может потребовать повторного подключения.

Чтобы убрать приложение: сначала выберите «Удалить подключение» в меню шестерёнки, затем «Завершить» и переместите приложение в Корзину. При необходимости удалите собственную папку `~/Library/Application Support/Audience Widget/` и настройки `app.audiencewidget.desktop.share`. API-ключ также можно отозвать в своём LiveDune.

## Исходники и проверка

MIT для собственного кода; SVG Threads/TikTok —Simple Icons CC0, см.THIRD-PARTY.md. Универсальный бинарник включаетarm64+x86_64; протестирован нативный запуск на Apple Silicon/macOS 26, Intel иmacOS 13–15 физически не запускались. Указанная минимальная версия —deployment target13.0.

Для самостоятельной сборки исходников нужны Xcode Command Line Tools/Swift и Python3 только как инструмент сборки:

```sh
python3 build.py
swiftc src/Core.swift src/LiveDune.swift tests/main.swift -o /tmp/audience-widget-tests
/tmp/audience-widget-tests
```

`python3 build.py --qa` собирает отдельную QAapp: сеть и Keychain в ней полностью отключены. Она не является распространяемым приложением. QA screenshot/fixtures не содержат реальных аккаунтов. Releaseapp лежит в `build/release/`. Персональных файлов, API-ключей и пользовательского state в ZIP нет.
